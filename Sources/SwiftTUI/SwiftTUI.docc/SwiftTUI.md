# ``SwiftTUI``

Build terminal applications with a declarative Swift API and a retained runtime.

## Overview

SwiftTUI provides an umbrella module for the framework's terminal, rendering, view, layout, animation, control, design, rich-text, and runtime modules.

``SwiftTUIRelease/version`` reports the version from the package's canonical `VERSION` resource.
