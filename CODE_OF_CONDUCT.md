# Code Of Conduct

TermKit contributors must keep project spaces respectful, inclusive, and focused on technical collaboration.

Acceptable conduct includes constructive feedback, clear technical disagreement, and respect for different experience levels.
Unacceptable conduct includes harassment, threats, discriminatory language, personal attacks, and publication of private information.

Maintainers can edit or remove contributions and restrict participation when conduct harms the community.
Report conduct concerns privately through the repository owner profile. Do not publish sensitive details in an issue.
